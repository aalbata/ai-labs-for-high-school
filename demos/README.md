# Browser demos

Both demos run in any modern web browser with nothing to install.

- `ai_demo.html` is the 15-minute opening: three short examples of AI being wrong, being biased and helping with design. A PowerPoint version is in the `slides` folder.
- `grid_world.html` is the reinforcement-learning lab: a robot learns to cross a grid from rewards and penalties. The worksheet is in the `guides` folder.

Online:

- https://aalbata.github.io/ai-labs-for-high-school/demos/ai_demo.html
- https://aalbata.github.io/ai-labs-for-high-school/demos/grid_world.html

You can also download either file and open it directly in a browser.
